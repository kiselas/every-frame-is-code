# motion-kit

Набор знаний для AI-агентов (Claude Opus и других), которые делают графику кодом: анимационные ролики, эксплейнеры, кинетическую типографику, переходы и монтаж, 3D-сцены и браузерные игры. Плюс скрипт покадрового рендера в MP4.

Принцип простой: модель не генерирует пиксели, а пишет программу, которая рисует каждый кадр. Такой ролик можно открыть в браузере, поправить одной строкой и перерендерить без потери качества.

## Быстрый старт

### Как скилл Claude Code

```bash
git clone https://github.com/kiselas/every-frame-is-code ~/.claude/skills/motion-kit
```

Claude Code подхватит `SKILL.md` и будет читать нужные файлы сам, когда задача про графику или анимацию.

### Как документация в проекте

Скопируй папку в `docs/motion/` и добавь в `CLAUDE.md`:

```
Перед любой работой с графикой, анимацией или играми прочитай docs/motion/00-agent-brief.md,
затем файлы, относящиеся к задаче.
```

### В чате

Прикрепи `00-agent-brief.md` и один-два тематических файла.

## Рендер

```bash
cd render && npm install
node render.mjs ../film.html ../film.mp4
./contact-sheet.sh ../film.mp4 ../sheet.png
```

Нужны Node 18+, Google Chrome и ffmpeg. Контракт страницы описан в `01-pipeline.md` и `render/README.md`.
