## 1. Цель и критерии приёмки

Сделать `examples/lyapunov/` v2: 45–60 с, 1080×1920, с закадровым голосом, вшитыми субтитрами и картинками, проходящими тест подписей; попутно дать киту инструменты озвучки, чтобы любой следующий ролик делался так же.

Принимается, когда:
1. Ролик понятен **без звука** (субтитры + картинки) и **со звуком** (голос ведёт историю). Пользователь смотрит оба режима.
2. Хук связывает тему с миром зрителя в первые 2 с; причинная цепочка «числа вручную → схема → программа собирает сама → слово под запретом → борьба результатами → школа» слышна и видна.
3. Каждая картинка проходит тест подписей (`21-infographics.md`); у каждого числа есть мерило в кадре и источник в подписи.
4. `node render/textcheck.mjs examples/lyapunov/film.html` без находок; `node render/music-report.mjs` без ошибок и предупреждений; `--loudnorm`: около −14 LUFS, true peak ≤ −1.5 dBTP; музыка под голосом приглушена на 10–15 дБ.
5. Все факты на экране и в голосе есть в таблице источников `SCRIPT.md`; спорные формулировки убраны (см. §4.3).
6. Инструменты (`render/voice.mjs`, приглушение в `render.mjs`, субтитры в `film.js`) задокументированы и покрыты проверками; тесты зелёные; `gps` и `pixel` не изменились (сравнить кадры `render/still.mjs` до и после).

## 3. Инструменты в ките (делать до ролика)

### 3.1 `render/voice.mjs`: текст → звук + тайминги слов

Node-скрипт (кит на Node; Python-зависимостей в ките нет, но Edge TTS проще всего из Python — см. вариант ниже). Интерфейс:

```
node render/voice.mjs script.txt out/voice            # Edge TTS, ru-RU-DmitryNeural
node render/voice.mjs script.txt out/voice --voice ru-RU-SvetlanaNeural --rate -5%
node render/voice.mjs script.txt out/voice --engine openrouter --model openai/gpt-4o-mini-tts --voice onyx
```

Вход: текстовый файл, абзац = фраза (пустая строка между абзацами = пауза; скрипт вставляет паузу 0.6 с, или SSML `<break>` для Edge). Выход:
- `out/voice.wav` (48 кГц, моно, ffmpeg из mp3/pcm);
- `out/voice.words.json`: `[{ "word", "start", "end", "phrase": i }]`, секунды, 3 знака;
- `out/voice.phrases.json`: `[{ "text", "start", "end", "words": [i0, i1] }]`;
- в stdout: длительность, число слов, слов/с, фразы с таймкодами.

**Edge TTS из Node.** Готовые npm-пакеты (`msedge-tts`, `edge-tts-universal`) работают через тот же WebSocket, что и Python-пакет, и отдают `WordBoundary`. Проверить один из них на `npm install` в `render/`; если он нестабилен или без таймингов, **вариант B**: `render/voice.py` на Python (`pip install edge-tts`; уже установлен в Python 3.8 на этой машине, версия 7.2.8), а `voice.mjs` вызывает его через `child_process`. В обоих случаях API Edge: `Communicate(text, voice, rate, boundary="WordBoundary")`, события `audio` и `WordBoundary` (`offset`, `duration` в 100-нс тиках). Рабочий Python-прототип этой сессии:

```python
import asyncio, json, sys, edge_tts
text, voice, out = sys.argv[1], sys.argv[2], sys.argv[3]
async def main():
    com = edge_tts.Communicate(text, voice, rate="-5%", boundary="WordBoundary")
    words = []
    with open(out + ".mp3", "wb") as f:
        async for ch in com.stream():
            if ch["type"] == "audio": f.write(ch["data"])
            elif ch["type"] == "WordBoundary":
                words.append({"word": ch["text"], "start": round(ch["offset"] / 1e7, 3), "end": round((ch["offset"] + ch["duration"]) / 1e7, 3)})
    json.dump(words, open(out + ".words.json", "w", encoding="utf8"), ensure_ascii=False)
asyncio.run(main())
```

Проба: 21 слово, 14.4 с при `-5%` (≈1.45 слова/с с паузами между предложениями; внутри фразы ≈1.8).

**OpenRouter:** `POST https://openrouter.ai/api/v1/audio/speech`, тело `{ model, input, voice, response_format: "pcm" | "mp3" }`, заголовок `Authorization: Bearer $OPENROUTER_API_KEY`. Таймингов слов он не отдаёт: для этого движка слова размечать через `faster-whisper`/`whisper.cpp` с `word_timestamps` (описано в `09-audio-sync.md`), либо распределять слова фразы равномерно по её длительности (пометить в JSON `"approx": true`). Документация: https://openrouter.ai/docs/guides/overview/multimodal/tts

Кэш: имя выходного файла включает хэш текста + голос + rate, повторный запуск с тем же текстом не ходит в сеть.

### 3.2 `render/render.mjs`: приглушение музыки под голосом

Сейчас `--voice` и музыка сводятся через `amix=inputs=N:normalize=0` без приглушения (строки ~181–189). Нужно:
- когда есть `--voice`: музыка (`__renderAudio` и/или `--music`) идёт через `sidechaincompress` от голоса: `[music][voice]sidechaincompress=threshold=0.03:ratio=8:attack=50:release=400:makeup=1`, затем `amix` с голосом; голос поднимается на `--voice-gain` (по умолчанию +0 дБ, музыка под голосом в итоге на 10–15 дБ тише);
- при `--loudnorm` цепочка как была: `loudnorm=I=-14:TP=-1.5:LRA=11, alimiter`;
- `--voice-offset S` (сдвиг голоса, по умолчанию 0) для подгонки старта;
- README: описать, с примером.

Проверка: отрендерить 10 с фрагмент с голосом и без, замерить `ffmpeg -af ebur128` на участке речи и в паузе; разница громкости музыки ≥ 10 LU.

### 3.3 `runtime/film.js`: субтитры из таймингов

Добавить в `Film.create` поле `voice`:

```js
voice: {
  words: VOICE_WORDS,            // из voice.words.json, вшито в страницу как данные (кит: страница самодостаточна)
  offset: .3,                    // секунда фильма, на которой начинается voice.wav
  at: 'bc',                      // зона; в портрете — над нижним отступом
  size: 62, font: null,          // размер и семейство (по умолчанию display)
  group: 'phrase' | 3,           // фразами из voice.phrases.json или по N слов
  highlight: true,               // текущее слово акцентным цветом
  box: true,                     // плашка под текстом (T.bg с alpha .85), чтобы читалось поверх картинки
}
```

Рисуется после HUD, до `post`. Фраза появляется на `start` первого слова (150 мс fade/подъём), исчезает через 250 мс после `end` последнего; слова подсвечиваются по своим таймингам. Экспорт `f.voice.phraseAt(t)`, `f.voice.time(word, n)` (время n-го вхождения слова: удобно привязывать события картинки к слову: «штамп ложится на слове "лжеучёным"»). Ширина фразы проверяется тем же механизмом подгонки, что и реплики (предупреждение в консоль, `textcheck.mjs` его поймает).

Тест в `browser.check.mjs`: фильм с 6 словами, кадры до/в середине/после фразы — текст есть/нет, подсветка меняется, предупреждений нет. Проверить, что без `voice` всё побайтно как раньше (`gps` стиллы).

### 4.1 Тезис, жанр, ставка

- **Жанр:** одна жизнь с рамкой «миф и факт» (`20-silent-social.md`), но с хуком через мир зрителя и с механизмом внутри (как в «как это работает»).

### 4.2 Текст голоса (черновик, 88 слов; длительности уточнить по TTS)

Абзац = фраза = субтитр(ы). Числа писать словами там, где TTS может прочитать неверно.

```

Алексей Ляпунов. Математик, артиллерист, ученик Лузина.

В пятьдесят втором первая советская машина понимала только числа. Программу набирали вручную, столбцами кодов. Одна ошибка — и всё заново.

Ляпунов предложил: сначала нарисуй схему. Операторы и условия. А код пусть соберёт программа.

Но само слово «кибернетика» в стране было под запретом.

Он отвечал результатами: десять лет семинара, первая статья в её защиту, совет при Академии наук.
```

### 4.3 Факты: что можно и чего нельзя говорить

Источники из `examples/lyapunov/SCRIPT.md` (Википедия, computer-museum.ru, letopis.msu.ru, kitov.rea.ru). Новые формулировки проверить и дописать в таблицу источников:

- **Нельзя:** «человек, который придумал схемы/блок-схемы». Блок-схемы программ — Голдстайн и фон Нейман, 1947. Ляпунов — операторный метод (запись программы как схемы операторов и логических условий) и идея программирующей программы в СССР; он *учил* этому (первый курс, 1952–53). Формулировка в тексте: «этому учил».
- «Первая советская машина понимала только числа» — МЭСМ (1951) / «Стрела»; программирование в машинных кодах. Держать общо, без марки машины, или назвать МЭСМ с источником.
- «Одна ошибка — и всё заново» — риторика, не число; не приписывать цифры часов.
- «Десять лет семинара»: семинар 1954–1964 (Википедия: «Автоматы и мышление»; computer-museum.ru: 1954–55, «работал 10 лет»). Ок.
- «Первая статья в её защиту»: Соболев, Китов, Ляпунов, «Вопросы философии» №4, 1955 — на экране все три фамилии (нельзя приписывать одному).
- «Совет при Академии наук»: Научный совет по кибернетике при Президиуме АН СССР, 1959, председатель Берг, зам. Ляпунов.
- «Его ученики написали компиляторы»: Ершов — ученик Ляпунова (Википедия), автор программирующей программы для БЭСМ (ПП БЭСМ, 1955–57) и языка Альфа; формулировку «написали компиляторы» подтвердить источником на Ершова (ru.wikipedia «Ершов, Андрей Петрович») и дописать в таблицу. Если не подтверждается — «его ученики строили первые компиляторы страны» заменить на «его ученик Ершов написал одну из первых в стране программирующих программ».

### 4.5 Переходы и темы

`push ↑` — следующий шаг; `dip` — смена главы/темы (`paper` ↔ `blueprint`); `punch` — препятствие; `cut` — тот же ход мысли. Кадры 4–5 в `blueprint`, остальные в `paper`.

### 4.6 Музыка

План `Compose.generate` как в v1 (A minor, `tense`, seed 5), но:
- секции по новым кадрам, сумма тактов = длине фильма;
- энергии ниже под речью: 0.15–0.5, пик 0.75 на `fight` (НАУКА), 0.1 на `end`;
- `gain: .55` вместо `.7`, остальное сделает приглушение в рендере;
- эффекты: удар штампа (кадр 2, 6), удар «НАУКА» (7), тиканье печати (5), whoosh на финал. События привязывать к словам через `f.voice.time(...)`, а не к долям.
- Прогнать `render/music-report.mjs`; читать piano roll и громкость по секциям.

### 4.7 Субтитры и экранный текст

- Субтитры: `voice.group: 'phrase'`, но фразы длиннее 4 слов `voice.mjs` режет по знакам препинания/паузам на 2–4 слова (в `phrases.json`).
- Экранная реплика (`say`) появляется на первом слове фразы, payoff-слово — на своём слове в голосе; реплика не дублирует субтитр дословно (тезис vs речь).
- Зона субтитров: над нижним отступом (`bc`), плашка; реплика — верхняя треть, как в v1; картинка — середина. Проверить, что субтитр не накрывает картинку: при необходимости поднять `safe[2]` до `.26`.
- Один размер реплик на весь фильм (как в v1: `size: 94`); `textcheck.mjs` без предупреждений.

## 8. Ловушки этой машины и репозитория

- **Bash tool на Windows:** команда длиннее ~5–6 КБ падает с `unexpected EOF while looking for matching`. Длинные скрипты и файлы писать инструментом Write, затем запускать. Python-heredoc'и до ~4 КБ работают.
- `cd` внутри команды сбрасывает cwd на следующий вызов; писать абсолютные пути.
- Python на машине 3.8 (`python`), `edge-tts` 7.2.8 установлен; флаг CLI `--write-subs` в этой версии не существует, использовать API с `boundary="WordBoundary"`.
- Кириллица в stdout Python через Bash печатается кракозябрами — это консоль, не данные; проверять через `json.load` или в файле.
- Google Fonts: `document.fonts.load(font)` без текста грузит только латиницу; `Film.create` уже грузит под реальный текст, но текст, рисуемый внутри `draw()`, нужно перечислить в `fontText`. Archivo без кириллицы; в ролике Oswald + IBM Plex Mono.
- Рендер 50 с в 1080×1920: ~3 мин на `--crf 18 --preset slow`, файл ~72 МБ; черновик `--draft` ~1.5 мин. Для фрагмента `--shot id`.
- `render/still.mjs` при `shot@p` — доля кадра; `scheme@0.95`.
- `runtime/film.js`: во время перехода входящий кадр рисуется с отрицательным `s.t`; всё, что строится на `s.seg()`/`s.at()`, это переживает; индексы массивов брать через `((k % n) + n) % n`.
- `music-report.mjs` читает `window.__score`; в фильме он выставлен.
- Факты в биографическом ролике — главный риск; каждую новую фразу голоса сверять с §4.3 и источниками в `SCRIPT.md` до записи.
